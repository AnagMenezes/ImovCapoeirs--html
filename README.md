ImovCapoeiras

O ImovCapoeiras é um projeto web desenvolvido com o objetivo de criar uma plataforma para divulgação de imóveis para venda e aluguel.

A ideia surgiu como um projeto de estudo, tendo como partida um problema real enfrentado da Cidade. Mas o objetivo é ir além de uma
aplicação acadêmica: pretendo continuar desenvolvendo o sistema, implementar novas funcionalidades e, futuramente, disponibilizá-lo para uso real.

-- Status do projeto

Em desenvolvimento

A versão atual representa a primeira etapa do projeto. Novas funcionalidades serão implementadas gradualmente conforme o desenvolvimento avançar.

-- Objetivo

Criar uma plataforma simples e acessível para divulgação de imóveis, permitindo organizar informações sobre propriedades disponíveis para venda ou aluguel.

-- Tecnologias

HTML5
CSS3
JavaScript

-- Funcionalidades atuais
Página inicial
Separação entre imóveis para venda e aluguel
Exibição de imóveis em cards
Página de detalhes dos imóveis
Galeria de imagens
Navegação entre imagens dos imóveis

-- Próximas etapas

Pretendo continuar evoluindo o projeto com funcionalidades como:
Implementar novas funcionalidades para os usuários
Melhorar o cadastro e gerenciamento dos imóveis
Aprimorar a busca e filtragem de imóveis
Melhorar a responsividade e a experiência de uso
Implementar um backend e banco de dados
Estruturar o rojeto para utilização real
Publicar a aplicação

- Sobre o projeto

O ImovCapoeiras também faz parte da minha trajetória de aprendizado em desenvolvimento web. A cada etapa, o projeto é utilizado para colocar em prática novos conhecimentos e experimentar diferentes soluções.

A intenção é continuar trabalhando nele até transformá-lo em uma aplicação realmente funcional e disponível para utilização.
